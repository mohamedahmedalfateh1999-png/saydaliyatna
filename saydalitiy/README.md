# منصة "صيدليتنا" - دليل صيدليات ولاية الخرطوم والبحث عن الدواء

نظام ويب متكامل مصمم بالكامل باستخدام تقنيات الويب القياسية **HTML5**, **CSS3**, **JavaScript (Vanilla)** بدون أي أطر عمل خارجية ثقيلة، مخصص لتسجيل الصيدليات في ولاية الخرطوم ومساعدة المواطنين على إيجاد الدواء ومقارنة أسعاره لتحديد **أرخص سعر متاح**.

---

## 🌟 أبرز مميزات المنصة

1. **محرك بحث ذكي للأدوية**:
   - البحث بالاسم التجاري (مثل: `Panadol`, `Augmentin`, `Concor`, `Ventolin`).
   - البحث بالاسم العلمي والمادة الفعالة أو الشركة المصنعة أو التركيز.
   - اقتراحات الإكمال التلقائي (Autocomplete) أثناء الكتابة.

2. **نظام مقارنة الأسعار وكشف "أرخص سعر ⭐"**:
   - مقارنة أسعار الدواء الواحد آلياً بين جميع صيدليات ولاية الخرطوم.
   - إبراز وتمييز الصيدلية التي تقدم أقل سعر ببطاقة وبادج ذهبي/أخضر بارز.
   - إمكانية التبديل بين عرض جدول المقارنة أو عرض البطاقات (Cards).

3. **تغطية شاملة لمناطق ولاية الخرطوم**:
   - فلترة مخصصة حسب: **الخرطوم، بحري، أم درمان، شرق النيل، كرري، أمبدة**.
   - فلترة حسب حالة الصيدلية: مفتوحة الآن / خدمة 24 ساعة.

4. **معالجة الحالات الخاصة**:
   - عند عدم وجود الدواء: *"عذرًا، لم يتم العثور على الدواء الذي تبحث عنه."*
   - عند وجود الدواء ونفاد كميته: *"الدواء مسجل في النظام ولكنه غير متوفر حاليًا."* مع زر تنبيه للمستخدم فور التوفر.

5. **تفاصيل متكاملة للصيدليات**:
   - العنوان الدقيق وساعات العمل.
   - أزرار اتصال هاتفي مباشر ومحادثة فورية عبر WhatsApp.
   - موقع الصيدلية على خرائط Google.
   - قائمة بجميع الأدوية المتوفرة في الصيدلية مع إمكانية البحث داخلها.

6. **تصميم عصري وطبي متجاوب 100%**:
   - يدعم اللغة العربية واتجاه اليمين إلى اليسار (RTL) بشكل مثالي.
   - خط **Cairo** المريح للقراءة.
   - أيقونات **FontAwesome 6**.
   - متوافق مع كافة أحجام الشاشات.

## 🚀 كيفية تشغيل الموقع

المشروع مصمم ليعمل مباشرة دون الحاجة لأي تثبيت معقد:

1. **التشغيل المباشر**:
   - افتح المجلد واضغط مرتين على ملف `index.html` ليفتح في أي متصفح (Chrome, Edge, Firefox, Safari).

2. **التشغيل عبر خادم محلي (مُوصى به لبيئة التطوير)**:
   - باستخدام إضافة **Live Server** في VS Code.
   - أو عبر Python:
     ```bash
     python -m http.server 8000
     ```
     ثم فتح المتصفح على: `http://localhost:8000`
